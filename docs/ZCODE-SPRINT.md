## Правила (кратко)

1. Работать только в своей ветке; `visual-rebuild` не трогать.
2. Сервер — единственный источник правды: никакого `Math.random`, расчётов цен и
   проверки победы на клиенте. Для тестов — сид.
3. `npm run typecheck` и `npm test` зелёные перед каждым коммитом в ветку.
4. Порт по умолчанию 3005; для экспериментов поднимать на свободном
   (`PORT=3999 SQLITE_PATH=/tmp/x.sqlite`), прод-база `tachka.sqlite` — не трогать.
5. Гонять сервер в `NODE_ENV=production` при проверках периметра: именно там видно,
   что `/dev/token` до сих пор доступен.
6. Конец волны — коммит в свою ветку, даже если задача не добита.
7. Приёмка — команда с ожидаемым выводом, а не «улучшено».
