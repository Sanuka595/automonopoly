# ADR 0006 · Монорепо server + client без сборщика на сервере

Дата: 2026-10. Статус: принят.

## Контекст

Сервер маленький (2 855 строк, ноль зависимостей кроме socket.io), выходной спринт —
минимум инструментов. Node 22+ умеет исполнять TS напрямую через
`--experimental-strip-types`. Клиенту сборщик нужен всё равно (React/Tailwind).

## Решение

Один репозиторий, две папки. Сервер: `node --experimental-strip-types server/index.ts`
(`package.json:9`), импорты с явным `.ts` (`server/room.ts:1-14`) — strip-types не
резолвит расширения сам. Тесты — встроенный `node --test` (`package.json:10`),
тайпчек — `tsc --noEmit` (`package.json:11`). Клиент — Vite + React 19 + Tailwind 4
(`client/package.json`), собирается в `client/dist`, который сервер раздаёт как статику
(`server/index.ts:61-72`).

## Следствия

- Мгновенный запуск без watch-сборки сервера; тесты стартуют без компиляции.
- strip-types не выполняет TS-трансформации: никаких enum/namespace/декораторов на
  сервере — только типы и `const`.
- Явные `.ts`-импорты обязательны и на клиенте тоже (`client/src/api/socket.ts:2`) —
  стиль единый, но непривычный после стандартного Vite-алиасинга.
- Версии node в engines `>=22` (`package.json:6`); на 20 всё упадёт на `node:sqlite`.
- Дубли конфига vite: `vite.config.ts` и скомпилированный `vite.config.js` лежат рядом —
  vite использует .js, при правке .ts нужно синхронизировать (FINDINGS-подобный нюанс
  замечен при чтении, код не трогали).
