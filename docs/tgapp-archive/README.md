# Архив TGAppNEW (Перекуп D6)

Снимок документации и игрового контента из репозитория
`Sanuka595/TGAppNEW` (последний пуш 2026-05-04). Сам репозиторий удалён.

Это **предыдущая итерация** игры, не спецификация «Тачки». Модели несовместимы:

- валюта в долларах и `decimal.js`, здесь целые евро `bigint`;
- 5 тиров авто (`Bucket/Scrap/Business/Premium/Rarity`) против 4 классов;
- несколько дефектов на авто со здоровьем 0–100 против одного дефекта;
- часть механик резолвилась на клиенте, без тестов.

Брать отсюда можно идеи и тексты, не код и не формулы.

## Что лежит

- `01`–`06`, `MECHANICS_CHECKLIST.md`, `MECHANICS.md` — документация старой версии.
- `newsDatabase.ts` — 10 рыночных событий с множителями цен. В «Тачке» новостей нет.
- `carDatabase.ts`, `defectDatabase.ts` — модели машин и дефекты старой версии.

Не перенесено: исходники клиента и сервера, промпты для агентов
(`CLAUDE.md`, `GEMINI.md`, `2604/CLAUDE_*.md`), отчёты о сессиях.
