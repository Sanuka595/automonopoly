# 07 Если что-то сломалось 🚑

Симптом → вероятная причина → что сделать. Всё проверено на живом коде 2026-10-31.

## Не грузится стол / «Подключение к столу...» 🔌

- **Сервер не поднят.** Подними: `PORT=3999 SQLITE_PATH=/tmp/tachka.sqlite npm start` — должен напечатать `Server listening on port 3999`.
- **Бот-токен пустой.** В логе будет `WARNING: BOT_TOKEN is empty…` — заполни `.env` в корне (файл не в git нарочно).
- **Собранный клиент смотрит не туда.** Адрес сервера при сборке задаёт переменная `VITE_SERVER_URL`; в dev-режиме работает прокси vite на порт 3005.

## Не пускает в комнату 🚫

- `initData: bad hash` — токен в `.env` не совпадает с ботом, из которого открыта ссылка.
- `initData: expired` — ссылке больше часа (`server/auth.ts:15`, лимит 3600 с). Перезайди в Mini App.
- `lobby is full` — за столом уже 4; это норма, не баг.

## Завис ход / никому не передаётся ⏳

- Подожди 30 с: сервер сам сделает автоход (`server/turn.ts:150`). При гонке/аукционе свои таймеры 10 с, при ничьей в гонке — ещё переброс.
- Если зависло навсегда — смотри лог сервера и перезапусти его. Партии после рестарта **не восстанавливаются** (см. ниже), начинать заново.

## Сервер перезапустился — партии пропали 🕳️

Это известное расхождение: RULES обещает восстановление из снимков, но код `loadRooms` ни к чему не подключён (файл `server/snapshot.ts:39` существует, в `server/index.ts` не вызывается). Пока чинится только подключением вызова при старте.

## Ставка на аукционе не проходит ❌

Нажатие +100/+500 даёт отказ `invalid bid step`. Причина: клиент шлёт сумму строкой, сервер сравнивает с числом — всегда мимо (граница сокета не приводит типы). Чинить на сервере: привести `intent.step` к bigint до `applyBid`. Пока ставку делает только тест.

## Займ не предлагается / падает возврат долга 💸

Та же болезнь строк: валидация `due < principal` сравнивает суммы как текст — «1000 < 200» кажется правдой. Офферы с разной длиной чисел отклоняются, а принятые падают в конце хода заёмщика. Чинить там же — приведение к bigint на границе.

## Гонку не начать / не ответить на вызов 🏁

Кнопок вызова, принятия и входа в пул в живом клиенте **нет вообще** — сервер умеет, интерфейс не дорисован. Пока гонка де-факто недоступна с телефона.

## Деньги ушли в минус 😱

> [!warning] Такого не бывает по коду
> Единственная функция списания `sub` (`server/money.ts:22`) физически запрещает отрицательный баланс и покрыта тестом. Если видишь минус — сначала проверь, не витрина ли это (`?mock=1` — статичная демка без сервера), а если живой стол — это баг, запиши состояние комнаты и цифры.

## Быстрая диагностика 🔬

| Команда | Что показывает |
|---|---|
| `curl -s http://127.0.0.1:3999/health` | жив ли сервер (`{"ok":true,...}`) |
| `npm test` | 33 теста; упавший — где сломались инварианты |
| `sqlite3 <файл>.sqlite "select state from rooms"` | сохранённый JSON комнаты (деньги в виде `{"$euro":"..."}`) |
| лог сервера | только старт и warning про токен — логов действий нет |
